# ADR-005: compound engineering deployment

## Status
Accepted

## Context
The package has extensive agent and supporting-file dependencies.

## Source package
compound-engineering

## Decision
Preserve the complete package and treat its skills, agents, scripts, templates, and policies as coupled.

## Alternatives considered
Independent SKILL copies and broad converter installation were rejected.

## Preserved functionality
Research, planning, review, compounding, agents, scripts, schemas, and templates remain.

## Excluded functionality
Unpinned, destructive, duplicated, or unproven activation is excluded.

## Host-specific differences
Native host plugins stay until parity; Codex portable links are namespaced.

## Validation method
Research, plan, review, knowledge, script, reference, and multi-agent fixtures.

## Consequences
Some network/API and host-specific skills remain conditional.

## Rollback method
Remove HHPE links and retain existing plugins.
