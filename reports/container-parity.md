# Container parity

The container contract is defined in `registry/adapters/hhpe-hrg/worker-contract.json`. It requires a read-only mount or verified bundle of immutable package sources, separate generated state, lock/capability/exposure/policy/tool manifests, and rejection on revision/tool/policy mismatch. The XLOTYL runtime binding supports the same metadata projection.

Actual container worker execution was not run in this continuation; result: `BLOCKED — no controlled worker image/launch target supplied`. No host absolute path is valid in the portable contract.
