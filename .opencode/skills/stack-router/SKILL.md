# HHPE stack router

Let the host discover skills. Select one primary owner for each responsibility: Superpowers for development method, Compound Engineering for research/planning/review/knowledge compounding, Ponytail for configured simplicity pressure, Caveman for configured communication compression, ast-grep for structural code operations, and tests for runtime verification. Avoid activating overlapping always-on process frameworks. Re-evaluate selection when the task phase changes. This router coordinates packages; it does not restate them.
